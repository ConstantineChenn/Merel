# MEREL 测试说明

记录日期：2026-11-28。此处对应本地演示版本，服务器更新后的验收需要另行执行。

## 方法与覆盖

| 方法 | 代表场景 | 断言 |
| --- | --- | --- |
| 等价类划分 | 合法值、空串、空白、null、错误类型、未知字段 | 接受有效输入；拒绝无效输入且不误写状态 |
| 边界值分析 | 消息 0/1/5000/5001 字符，标识 7/8/100/101 字符，状态 -1/0/3/4 | 状态码与数据变化符合约束 |
| 条件组合 | 无身份、跨用户、非同源、旧版本、同标识不同内容 | 分别返回 401/404/403/409，归属检查成立 |
| 状态迁移 | 新建、发送、修订状态、反馈、计划、完成、归档、恢复、删除 | 版本递增、记录持久化、关联清理 |
| 幂等与并发 | 同请求重放、生成中重复请求、生成期间修改或删除 | 不重复生成，不提交过期结果，不恢复已删除对象 |
| 故障注入 | 503、无效响应、响应丢失、模型失败、409 | 反馈可见，内容保留，恢复路径有效 |
| 资源竞争 | 快速切换表情，旧图晚到，预览/高清分别失败 | 当前图不被旧图覆盖，预览保留且可重试 |

更多边界包括标题 1/80/81、称呼 1/30/31、持续天数 -1/0/3650/3651、反馈评分 0/1/5/6、备注 0/1000/1001。

- Python unittest：**61 个测试方法通过**。参数化子场景包含在方法内，不另外累计为测试方法。

```bash
python -m unittest discover -s tests -p "test_*.py" -v
node tests/test_expressions.mjs
```

```bash

```

该脚本使用独立 Cookie，发送两条合成输入验证真实模型，并清理自身创建的对话；结果写入被 Git 忽略的 `test-results/http-acceptance.json`。此脚本会产生实际模型调用。

## 真实在线与浏览器验收

最近一次 HTTP 验收：问候回复约 **2.14 秒**、普通支持约 **11.19 秒**。最近一次浏览器验收：分别约 **1.76 秒**和 **14.02 秒**。四次均为 `generator=llm`；两次普通支持为 `extractor=llm_structured`，无回退警告。

浏览器的 **7 组故障场景**通过：空白/中文输入法/换行、连续发送与刷新、已提交响应丢失后的幂等重试、无效 JSON 恢复、503 恢复、409 同步重发、生成期间切页后结果保留。故障注入使用确定性模型，以单独验证客户端恢复行为。

另有 **6 组在线演示场景**覆盖立绘和导航预览、高清替换、表情册、箭头与 Enter 的在线回复、高清失败保留手机导航预览，以及预览失败后的高清显示。

## 图片与限速结果

34 份无损高清 WebP 与原始素材逐像素比较 RGBA 数据和尺寸，一致。原始合计 **203.69 MB**，高清 WebP 合计 **78.82 MB**，全部低清预览约 **589 KB**。来源记录见素材目录，当前资源路径由 `frontend/image-catalog.js` 维护。

**6 组图片专项**通过：全部预览解码、全部高清尺寸/并发上限、旧高清迟到、旧预览迟到、失败后重新显示重试、冷缓存限速加载。

单次限速条件为 Chrome 手机尺寸模拟，390×844 CSS 像素、DPR=3、下载 128000 字节/秒、120 ms 延迟。此前无背景音乐时，低清立绘约 **2.96 秒**出现，高清约 **39.41 秒**替换。加入音乐后的版本复查为 **3.01 秒**与 **66.85 秒**；音乐也会消耗带宽，高清替换取决于实际下载速度，不使用固定倒计时。

## 背景音乐与自动换图复查

`tests/test_media_browser.cjs` 覆盖 8 组场景：34 张低清图自动升级至原尺寸高清、AAC 实际播放及 HTTP Range、顺序预下载、四段切换循环及跨页面播放、首段请求失败恢复、后续预下载失败恢复、禁止自动播放时键盘启动、手机尺寸触摸启动。全部通过；手机场景使用 Chromium 模拟，不代表真实 iOS Safari 设备验收。

自动播放限制场景使用 CDP 的 `userGesture: false` 检查初始状态，避免测试框架执行 JavaScript 时意外授予用户激活。《悲怆》四段均通过全程解码、180 秒时长、AAC 双声道格式及首秒音频信号检查。逐段快进至结尾验证一→二→三→四→一，已预下载的段落不会再次请求。

在独立测试实例启动后运行：

```bash
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/test_media_browser.cjs http://127.0.0.1:8787
```

该测试会创建临时浏览器会话及空对话，不调用模型；请使用独立测试数据库。报告及低清/高清截图保存在被 Git 忽略的 `test-results/`。

## 本次修复

新增 `node tests/test_portrait_priority.cjs http://127.0.0.1:8787` 专项，检查封面独占优先、点击表情预载、高清保持、缓存复用、失败重试、加载中换页与超时恢复。高清使用同源 fetch 和页面内 Blob URL 复用，避免显示已预载资源时再次下载；这不会改变图片的像素或压缩格式。

优先调度版本的同类单次限速复查：低清约 **3.03 秒**，封面高清约 **32.72 秒**。此前音乐与图片并行的版本约为 **66.85 秒**；这是单次测试对比，不是延迟保证。

1. 发送按钮调用 `crypto.randomUUID()` 在非安全 HTTP 上下文抛错；改为使用 `crypto.getRandomValues()`。
2. 中文“这两天”等明确天数无法通过提取结果校验；补充解析与回归测试，模糊的“两三天”不强行确定天数。
3. 原渐进加载仅覆盖部分资源；统一接入全部 34 份素材，增加可见性调度、并发控制和切换竞态保护。
4. 解包后表情测试仍引用旧 PNG 目录；更新为验证完整的预览/高清映射。

以上是功能与故障回归证据，未进行并发容量压测、真实 iOS Safari 设备测试或新版服务器验收；少量模型耗时不用于宣称性能分位数或临床有效性。

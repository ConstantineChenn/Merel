# MEREL 演示流程

建议使用新建的演示会话和合成输入。启动方式见 [部署说明](deployment.md)。

## 1. 进入与问候

打开页面，展示人物、输入区和“展开空间”按钮。先输入“你好呀”，点击箭头发送；说明纯问候进入日常交流分支，不强行新增心理状态记录。

## 2. 带入具体处境

输入：“这两天准备答辩有些累，想先安排一个轻松的小步骤。”

用 Enter 发送，观察生成状态和回复。打开研究回放，核对：

- 本轮实际生成方式是否为 `llm`。
- 状态提取是否使用 `llm_structured`，持续天数是否正确。
- 哪一项支持动作被选择，以及其他候选的规则分值。
- 模型调用、复核、耗时与回退警告。

演示时明确当前排序是规则实现，角色语言层负责将已选动作表达为自然对话。

## 3. 状态修订与反馈

进入状态记录，修订一项合成状态并保存，展示用户可以校正系统记录。回到回复，对帮助度和行动负担进行评分。

## 4. 小计划与回放

将本次支持动作加入小计划，标记完成，再展示归档或恢复。返回研究回放核对这轮输入、状态、动作、回复和反馈，最后导出 JSON。

## 5. 图片加载与恢复

展开空间导航，展示 5 个表情图标；在设置中打开表情册切换神态。图片先加载对应低清预览，再在后台下载完整无损图，快速切换时不会被旧图覆盖。

已有缓存时低清阶段可能很短；演示加载顺序可使用浏览器的禁用缓存与限速功能。网络或模型失败时查看实际提示与执行轨迹，不将本地回退描述为在线模型结果。
